# List Types, Functions, and Daily Usage

Welcome to the **List** repository! This project serves as a foundational guide and reference for working with lists in Python. It is designed for beginners to understand list structures, built-in methods, and practical daily use cases.

## 📂 Repository Structure

The folder contains the following core files:
* **`list.py`**: Core examples demonstrating basic list creation, indexing, slicing, and fundamental operations.
* **`list2.py`**: Advanced operations, list comprehensions, and practical daily coding scenarios using lists.


---

## 🚀 Key Concepts Covered

### 1. Basic List Operations
* Creating, indexing, and slicing lists.
* Modifying elements and understanding list mutability.

### 2. Built-in List Functions
* Adding items: `.append()`, `.extend()`, `.insert()`
* Removing items: `.pop()`, `.remove()`, `.clear()`
* Utility methods: `.sort()`, `.reverse()`, `.index()`, `.count()`

### 3. Practical Daily Usage
* Iterating through lists using loops.
* Using list comprehensions for cleaner, faster code.
* Basic data filtering and transformations.

---

## 🛠️ How to Run the Code

1. Make sure you have Python installed on your system.
2. Clone or download this repository.
3. Open your terminal or command prompt and run either file:

```bash
# To run basic list operations
python list.py

# To run advanced operations and use cases
python list2.py
```
